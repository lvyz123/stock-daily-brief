# 每周股市简报

给一位个人投资者写一份中文周报：复盘过去一周三大市场，预测下周板块机会。他最关注美股，尤其是 AI 科技与半导体产业链；其次是港股和 A股。

## 步骤

### 1. 抓数据

在 `D:/stock-daily-brief` 下运行：

```bash
cd /d/stock-daily-brief && ./.venv/Scripts/python.exe -m brief.weekly
```

约需 2 分钟，输出 `D:/stock-daily-brief/out/weekly_data.md`：三地指数、板块周度排名、AI/半导体各细分成分明细、个股涨跌排行、A股板块榜、未来三周美股 AI/半导体财报日程。用 Read 读取它。

数据源出问题时（某个市场标的大量缺失），在报告里说明，不要编造数字。

### 2. 联网补充

数据包只有价格，涨跌原因和下周催化剂要靠搜索。用 WebSearch / WebFetch 做 6–12 次检索，围绕：

- 本周美股 AI/半导体里涨跌最猛的那几个细分和个股，原因是什么
- 其他本周表现亮眼的板块，驱动是什么
- 下周的催化剂：财报（对照数据包里的财报日程）、宏观数据与美联储事件、重要发布会与行业会议、政策
- 港股、A股只在确有值得写的板块时才检索

搜索是为了解释和预判，不是为了罗列新闻。

### 3. 写报告

**内容规则**（用户明确提过的要求）：

1. 聚焦板块本身的走势与驱动，不做新闻汇总。只有当某个事件是解释涨跌或机会逻辑所必需时才提及，一句话说清它如何作用于板块。
2. 取舍比完整更重要：
   - AI 科技与半导体必写，按细分展开（算力GPU、定制ASIC/互连、存储/HBM、代工、设备、EDA/IP、光互连/网络、AI服务器、AI电力/散热、云厂商、AI软件等），只写有显著异动的细分。
   - 其他板块只写两类：①过去一周表现亮眼的，讲清上涨原因，并判断后面是否还有机会；②你认为下周或未来两三周有较好机会的，讲清逻辑。既不亮眼、也看不到机会的板块完全不提。
3. 篇幅：美股优先，约占全文 55–60%；港股、A股精简，没什么机会时几段话即可。全文 2000–3500 字。
4. 展望要具体、可验证：AI/半导体里有上涨机会的方向写得相对详细，具体到细分板块，尽量给出代表个股，说明逻辑（资金、技术面、基本面、催化剂）、时间窗口、信心（高/中），以及什么情况下判断失效。个股推荐不是必须的，只推荐真正有把握的。没有把握就写“方向不明，观望”，不要凑数。下行风险简短提示。
5. 数据纪律：数据包里的行情表是价格与涨跌幅的唯一来源，引用数字必须与表格一致，不要编造或凭记忆给出价格。
6. 不给仓位、杠杆之类的个性化建议；结尾放一句免责声明。

**结构**：

- 本周要点：3–5 条，每条一句话，美股 AI/半导体优先
- 美股：大盘一句话 → AI 与半导体（按细分复盘）→ 其他亮眼板块 → 下周展望（AI/半导体机会在前，其他机会随后）
- 港股：复盘与展望合并，精简
- A股：同上
- 下周关键日程：财报、宏观事件，列表形式，简短

### 4. 输出成网页

先加载 `artifact-design` 技能（要画图表时再加载 `dataviz`），然后写 HTML 页面并用 Artifact 工具发布。页面要求：

- 顶部是行情快照表：三地指数的本周涨跌，以及美股 AI/半导体各细分的本周涨跌。**红涨绿跌**（中国习惯）。
- 正文分市场排版，小标题清晰，手机宽度下可读。
- 每条推荐标注时间窗口和信心。
- 底部放免责声明和数据截止时间。

页面写到临时目录后发布，然后在对话里给出链接，并附 3–5 句话的核心结论，方便不点开也能看懂大意。

### 5. 存档

报告正文（Markdown）存到 `D:/stock-daily-brief/reports/weekly-YYYY-MM-DD.md`（北京日期），推荐列表存到同目录的 `weekly-picks-YYYY-MM-DD.json`（字段：market、code、name、segment、horizon、confidence、thesis、ref_price）。

下次生成周报时，先看 `D:/stock-daily-brief/reports/` 里最近一期：在新报告里用一小节回顾上期推荐的表现（用数据包里的最新价格对比 ref_price），并说明观点是否变化、为什么。

## 备注

- 代码格式：美股用交易代码（NVDA），港股用 hk 加 5 位数字（hk00981），A股用 sh/sz 加 6 位数字（sz300308）。
- 想增删关注的标的，改 `D:/stock-daily-brief/brief/universe.py`，改完跑 `python -m brief.market_data` 自检。
- 这个项目原本是每日邮件简报（`main.py`），因为拿不到 Anthropic API Key，改成了在对话里手动生成的周报。数据抓取、指标计算、板块定义复用原来的代码。
